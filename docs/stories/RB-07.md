## User story

As a chat user, I can query only fully indexed documents so partial ingestion does not produce misleading evidence.

## Scope

Implement the selected real embedding integration; insert vectors and full-text metadata in `doc_chunks`; publish ready revision and document chunk count only after successful indexing. Persist provider/model identity, job timings, and classified failure details.

## Tasks

- [x] Implement the selected real embedding integration
