# RB-23 — Schedule repeatable regression checks

Part of [Sprint 6 — Observable PoC](../SPRINT_PLAN.md#4-detailed-stories). This story inherits the shared [definition of ready and done](../SPRINT_PLAN.md#5-shared-definition-of-ready-and-done).

**Status:** Not started

**Sprint:** Sprint 6 — Observable PoC

**Priority / Size / Owner:** P1 · M · pipeline/evaluation

**Depends on:** [RB-18 — Execute bounded parameter experiments](RB-18.md), [RB-19 — Compare runs with persisted regression policy](RB-19.md), [RB-21 — Aggregate operational and quality metrics](RB-21.md)

## User story

As an evaluator, I can schedule a benchmark against an explicit baseline so regressions are detected without manually rebuilding run settings.

## Scope

Add an opt-in Airflow schedule using the existing evaluation/comparison workflow, not a second evaluator. Persist dataset/config/corpus/baseline/policy identities and execution status; document local enable/disable behavior.

## Tasks

- [ ] Add an opt-in Airflow schedule that reuses the existing evaluation/comparison workflow, not a second evaluator
- [ ] Persist dataset/config/corpus/baseline/policy identities and execution status for scheduled runs
- [ ] Record pass/regression/not-evaluable with reasons visible through existing APIs/UI
- [ ] Produce an explicit job failure/not-evaluable state for missing baseline, unavailable corpus, or evaluator failure
- [ ] Keep local schedules disabled by default and document local enable/disable behavior

## Acceptance criteria

- [ ] A scheduled execution uses the pinned benchmark and policy and records pass/regression/not-evaluable with reasons visible through existing APIs/UI.
- [ ] Missing baseline, unavailable corpus, or evaluator failure produces an explicit job failure/not-evaluable state, not a pass.
- [ ] Local schedules are disabled by default to avoid accidental provider spending; no external alerting platform is required.

## Verification

Exercise one scheduled interval in an isolated environment with explicit provider authorization; inspect run/comparison records, then disable it. Test missing-baseline behavior with a controlled fixture.
