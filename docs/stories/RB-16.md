## User story

As an evaluator, I can select a dataset/config, launch a run, and inspect individual failures so evaluation is usable without database access.

## Scope

Build Evaluations dataset/config selectors, run action/status, aggregate cards, per-question answer/evidence/score views, and trace links. Add dataset import/versioned-edit controls against RB-13 contracts.

## Tasks

- [x] Build Evaluations dataset and config selectors on the existing API client
- [x] Implement run launch action and accurate run status display (terminal or partial state, no fake progress)
- [x] Build aggregate cards that keep quality, efficiency, and failure counts separate
- [x] Build per-question answer/evidence/score views with links to each case's evidence and trace
- [x] Add dataset import and versioned-edit controls against the [RB-13](RB-13.md) contracts
- [x] Keep invalid dataset, failed launch, missing score, and failed case states visible after reload

## Acceptance criteria

- [x] A versioned dataset can be maintained and selected; a launched run reaches an accurate terminal or partial state without fake progress.
- [x] Aggregate cards keep quality, efficiency, and failure counts separate; each case leads to its evidence and trace.
- [x] Invalid dataset, failed launch, missing score, and failed case states remain visible after reload.
