# RB-10 — Generate grounded answers and citations

Part of [Sprint 3 — Traceable chat](../SPRINT_PLAN.md#4-detailed-stories). This story inherits the shared [definition of ready and done](../SPRINT_PLAN.md#5-shared-definition-of-ready-and-done).

**Status:** Not started

**Sprint:** Sprint 3 — Traceable chat

**Priority / Size / Owner:** P0 · L · backend

**Depends on:** [RB-09.md](RB-09.md)

## User story

As a reviewer, I receive an answer supported by retrieved chunks so I can check its evidence.

## Scope

Implement `POST /api/v1/chat`; versioned prompt construction, context budgeting, selected real generation provider, response parsing, and citation mapping. Keep the pipeline callable by normal chat and evaluation.

## Tasks

- [ ] Implement `POST /api/v1/chat`
- [ ] Implement versioned prompt construction and context budgeting
- [ ] Integrate the selected real generation provider
- [ ] Implement response parsing and citation mapping to retrieved evidence
- [ ] Keep the pipeline callable by both normal chat and evaluation
- [ ] Make prompt version, model profile, and the context actually sent recoverable; treat document text as evidence, not higher-priority instructions
- [ ] Surface missing/invalid citations and malformed responses as visible failures, and use the documented taxonomy for timeout and rate-limit errors, with no fabricated fallback answer

## Acceptance criteria

- [ ] A real model answer returns the API sketch's answer/citations shape, with citations mapped only to retrieved evidence.
- [ ] Prompt version, model profile, and context actually sent are recoverable. Document text is treated as evidence, not higher-priority instructions.
- [ ] Missing/invalid citations and malformed responses are visible failures; timeout and rate-limit errors use the documented taxonomy. No fallback fabricated answer is returned.

## Verification

Authorized grounded-question smoke run; controlled tests for outside-context citation IDs, `citation_missing`, `malformed_response`, `model_timeout`, and `model_rate_limited`.

Verification checklist (to be completed during implementation):

- [ ] Authorized grounded-question smoke run completed
- [ ] Controlled tests pass for outside-context citation IDs, `citation_missing`, `malformed_response`, `model_timeout`, and `model_rate_limited`
