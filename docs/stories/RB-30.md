# RB-30 — Orchestrate extraction, validation, and reporting as an agent workflow

Part of Sprint 7 — Document intelligence assessment. This story inherits the shared definition of ready and done in `docs/SPRINT_PLAN.md`.

**Status:** Not started

**Sprint:** Sprint 7 — Document intelligence assessment

**Priority / Size / Owner:** P0 · M · backend + pipeline

**Depends on:** RB-27, RB-28, RB-29

## User story

As an assessment reviewer, I can observe a simple agent workflow calling named tools in a safe order and producing a concise final report only after extraction and validation are complete.

## Scope

Add a bounded `DocumentIntelligenceAgent` orchestration contract around named tools/functions. Airflow may own asynchronous stage orchestration, while Go retains domain/tool contracts and validation semantics. Avoid a general-purpose agent framework.

## Tasks

- [ ] Define named tool interfaces for text extraction, structured extraction, validation, and summary generation
- [ ] Enforce stage order: extract -> structured extract -> schema validation -> financial validation -> summary
- [ ] Persist stage/tool status and correlation identifiers
- [ ] Generate a concise summary using structured data plus validation findings
- [ ] Ensure summary clearly reflects material validation warnings/failures instead of hiding them
- [ ] Define bounded retry rules by failure class; do not retry deterministic validation failures as model errors
- [ ] Return/persist a final result containing document ID, structured data, validation findings, summary, and trace identity
- [ ] Add workflow tests for success, extraction failure, LLM malformed output, validation warning, and summary-provider failure
- [ ] Update architecture and `ENGINEERING_NOTES.md`

## Acceptance criteria

- [ ] Runtime evidence shows the agent calling the required tools/functions in the documented order.
- [ ] Validation always completes before summary generation is accepted as final.
- [ ] A stage failure creates a visible failed/partial state with correlation evidence; no later stage silently fabricates success.
- [ ] Final successful result includes structured data, validation output, concise summary, and trace/correlation identity.
