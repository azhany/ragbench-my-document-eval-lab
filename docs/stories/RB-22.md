# RB-22 — Deliver Overview and Monitor surfaces

Part of [Sprint 6 — Observable PoC](../SPRINT_PLAN.md#4-detailed-stories). This story inherits the shared [definition of ready and done](../SPRINT_PLAN.md#5-shared-definition-of-ready-and-done).

**Status:** Implemented; browser walkthrough remains a release verification step

**Sprint:** Sprint 6 — Observable PoC

**Priority / Size / Owner:** P1 · M · frontend

**Depends on:** [RB-20 — Show configuration differences and comparison results](RB-20.md), [RB-21 — Aggregate operational and quality metrics](RB-21.md)

## User story

As a reviewer, I can inspect system health and navigate to the evidence behind a metric or failure.

## Scope

Build Overview summary and Monitor success/error, latency, token/cost and quality trends, recent traces/failures, trace span view, and links back to Library/Evaluations. Reuse existing summary/detail APIs rather than add a dashboard backend.

## Tasks

- [x] Build the Overview summary surface
- [x] Build Monitor views for success/error, latency, token/cost, and quality trends
- [x] Build recent traces/failures lists and the trace span view
- [x] Link failures to persisted trace, evaluation or ingestion detail paths
- [x] Reuse existing summary/detail APIs; no dashboard backend was added
- [x] Keep loading, no-data, missing metric, and API failure states distinct

## Acceptance criteria

- [ ] All six documented navigation destinations now offer real workflows, not unavailable placeholders.
- [ ] Filters and metric units are visible; selecting a failure reaches its actual trace, evaluation result, or ingestion status.
- [ ] Loading, no-data, missing metric, and API failure states remain distinguishable; displayed values are database-backed.

## Verification

Browser-drive each destination, apply a time filter, open a failed ingestion/query/evaluation, and inspect a trace's evidence and spans; compare selected cards with API values.
