# RB-07 — Embed and publish searchable revisions

Part of [Sprint 2 — Document library](../SPRINT_PLAN.md#4-detailed-stories). This story inherits the shared [definition of ready and done](../SPRINT_PLAN.md#5-shared-definition-of-ready-and-done).

**Status:** Not started

**Sprint:** Sprint 2 — Document library

**Priority / Size / Owner:** P0 · L · pipeline/database

**Depends on:** [RB-06.md](RB-06.md)

## User story

As a chat user, I can query only fully indexed documents so partial ingestion does not produce misleading evidence.

## Scope

Implement the selected real embedding integration; insert vectors and full-text metadata in `doc_chunks`; publish ready revision and document chunk count only after successful indexing. Persist provider/model identity, job timings, and classified failure details.

## Tasks

- [ ] Implement the selected real embedding integration
- [ ] Insert vectors and full-text metadata in `doc_chunks`
- [ ] Publish the ready revision and document chunk count only after successful indexing
- [ ] Persist provider/model identity, job timings, and classified failure details
- [ ] Record partial embedding failure as `embedding_failed` with useful stage context, without publishing an incomplete revision
- [ ] Make retry complete without duplicate chunks
- [ ] Prevent revisions from incompatible embedding profiles being mixed in one retrieval query

## Acceptance criteria

- [ ] A real-provider smoke run stores vectors with the configured dimensions and FTS content; the document transitions to processed with the actual chunk count.
- [ ] Partial embedding failure does not publish an incomplete revision. Provider errors are recorded as `embedding_failed` with useful stage context.
- [ ] Retry completes without duplicate chunks; revisions from incompatible embedding profiles cannot be mixed in one retrieval query.

## Verification

Small authorized real embedding run, database vector/FTS query, and dimension/partial-failure/idempotency integration tests using controlled provider doubles for deterministic failures.

Verification checklist (to be completed during implementation):

- [ ] Small authorized real embedding run completed
- [ ] Database vector/FTS query returns indexed content
- [ ] Dimension, partial-failure, and idempotency integration tests pass using controlled provider doubles
