# RB-20 — Show configuration differences and comparison results

Part of [Sprint 5 — Measurable experiments](../SPRINT_PLAN.md#4-detailed-stories). This story inherits the shared [definition of ready and done](../SPRINT_PLAN.md#5-shared-definition-of-ready-and-done).

**Status:** Not started

**Sprint:** Sprint 5 — Measurable experiments

**Priority / Size / Owner:** P1 · M · frontend

**Depends on:** [RB-16 — Run and inspect evaluations in the UI](RB-16.md), [RB-18 — Execute bounded parameter experiments](RB-18.md), [RB-19 — Compare runs with persisted regression policy](RB-19.md)

## User story

As an evaluator, I can see which configuration is better and by how much, including its cost/latency tradeoffs.

## Scope

Implement Experiments config creation/detail, bounded matrix launch/status, baseline selection, config diff, side-by-side metrics/deltas, regression reasons, and per-case drill-down from Evaluations.

## Tasks

- [ ] Implement Experiments config creation and detail views
- [ ] Implement bounded matrix launch and status views
- [ ] Implement baseline selection and a visible config diff
- [ ] Implement side-by-side metrics/deltas and regression-reason display, keeping quality and efficiency separate
- [ ] Implement per-case drill-down from Evaluations into a run's case trace
- [ ] Display reasons for incompatible comparisons, missing metrics, and partial experiments, with unambiguous delta units and metric direction
- [ ] Identify unavailable optional reranking rather than implying it ran (depends on [RB-25](RB-25.md))

## Acceptance criteria

- [ ] UI exposes all implemented PRD tuning fields and identifies unavailable optional reranking instead of implying it ran.
- [ ] Baseline and candidate dataset/config/index/policy identities are visible; quality and efficiency remain separate, including cases with no single overall winner.
- [ ] Incompatible comparisons, missing metrics, and partial experiments display their reason; delta units and metric direction are unambiguous.

## Verification

Browser-create two configs, launch a small experiment, compare runs, inspect a case trace, and attempt an incompatible comparison; check displayed deltas against API results.
