## User story

As an evaluator, I can run a small configuration matrix so chunking and query changes are measured systematically.

## Scope

Implement `rag_parameter_sweep`, proposed experiment create/list/detail APIs, and persisted experiment-to-config/run links. Resolve required index revisions through `document_reindex`, then launch evaluations. Support chunk size/overlap, top-k, vector/hybrid, prompt version, model profile, and the executable rerank dimensions from RB-25.

## Tasks

- [x] Implement the `rag_parameter_sweep` DAG
- [x] Implement proposed experiment create/list/detail APIs and persisted experiment-to-config/run links
- [x] Resolve required index revisions through `document_reindex` before launching evaluations; prevent evaluation against the wrong corpus after a failed reindex
- [x] Support the configuration matrix dimensions: chunk size/overlap, top-k, vector/hybrid, prompt version, model profile, and rerank settings
- [x] Persist the expanded configuration matrix before execution with an explicit configured combination limit
- [x] Reject invalid/unsupported combinations visibly and retain successful run links on partial matrix failures
- [x] Make retries idempotent so they do not create duplicate logical experiments/runs

## Acceptance criteria

- [ ] Persist the expanded configuration matrix before execution with an explicit configured combination limit; a two-configuration experiment produces separate traceable runs.
- [x] Chunk/embedding changes build compatible revisions before evaluation; query-only changes reuse compatible ready revisions. A failed reindex prevents that config from being evaluated against the wrong corpus.
- [x] Invalid/unsupported combinations are rejected visibly, and partial matrix failures retain successful run links. Retries do not create duplicate logical experiments/runs.

## Verification

Two-config sweep including a chunk-size change; inspect different index identities and the same dataset/source corpus; controlled reindex failure and task retry; no hidden fallback to the old index.

Live evidence: experiment `fe76c7fe-86f4-4708-848a-6eded0b80db2` persisted two deterministic config identities and exposed the failed reindex without launching evaluations against the prior active revisions.
