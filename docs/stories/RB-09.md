# RB-09 — Retrieve ranked vector evidence in Go

Part of [Sprint 3 — Traceable chat](../SPRINT_PLAN.md#4-detailed-stories). This story inherits the shared [definition of ready and done](../SPRINT_PLAN.md#5-shared-definition-of-ready-and-done).

**Status:** Not started

**Sprint:** Sprint 3 — Traceable chat

**Priority / Size / Owner:** P0 · M · backend

**Depends on:** [RB-03.md](RB-03.md), [RB-07.md](RB-07.md)

## User story

As a reviewer, I can ask across processed documents and retrieve the most relevant available evidence.

## Scope

Implement query validation, query embedding, pgvector retrieval, top-k truncation, and evidence identity in the Go query pipeline. Restrict retrieval to selected compatible ready revisions and record stage timing.

## Tasks

- [ ] Implement query validation in the Go query pipeline
- [ ] Implement query embedding
- [ ] Implement pgvector retrieval with top-k truncation
- [ ] Return ordered evidence with chunk/document/revision identity and source content
- [ ] Restrict retrieval to selected compatible ready revisions; exclude deleted or unpublished revisions
- [ ] Record stage timing for the retrieval path
- [ ] Return the documented insufficient-evidence outcome (`retrieval_empty`) for empty retrieval, without inventing an answer or silently selecting unrelated context
- [ ] Return distinct structured errors for unknown config, unavailable revision, and embedding failure

## Acceptance criteria

- [ ] Results are ordered and capped by top-k, with chunk/document/revision identity and source content; deleted or unpublished revisions are excluded.
- [ ] Empty retrieval returns the documented insufficient-evidence outcome (`retrieval_empty`) without inventing an answer or silently selecting unrelated context.
- [ ] Unknown config, unavailable revision, and embedding failure are distinct structured errors.

## Verification

Known-vector ranking, ties, top-k, no-result and revision-filter tests against pgvector; authorized query-embedding/retrieval smoke run on the Sprint 2 corpus.

Verification checklist (to be completed during implementation):

- [ ] Known-vector ranking, tie, top-k, no-result, and revision-filter tests pass against pgvector
- [ ] Authorized query-embedding/retrieval smoke run completed on the Sprint 2 corpus
